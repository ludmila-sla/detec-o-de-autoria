# Literary Authorship Detection using Neural Networks

This repository contains the code and experimental setup used in the study "Literary Authorship Detection using Neural Networks and Natural Language Processing".

## Objective

Compare MLP and LSTM neural network architectures for literary authorship attribution using texts from Project Gutenberg.

## Dataset

* Edgar Allan Poe
* Arthur Conan Doyle
* Mary Shelley

Texts were obtained from Project Gutenberg.

## Methods

* TF-IDF + MLP
* Tokenization + LSTM

## Experiments

The models were evaluated using text segments of 100, 200 and 300 words.

## Requirements

Python 3.10+

Main libraries:

* TensorFlow
* Scikit-learn
* Pandas
* NumPy
